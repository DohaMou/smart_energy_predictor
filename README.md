# Smart Energy Predictor

Prévision de la consommation électrique, détection d'anomalies et conseils
d'économie d'énergie, à partir des données ouvertes Enedis (Hauts-de-France)
et de la météo de Calais.

**Statut :** en construction

## Stack
Python, Pandas, Scikit-learn, XGBoost, PostgreSQL, FastAPI, Streamlit, React Native, Docker

## Sources de données
- Enedis Open Data
- Open-Meteo
